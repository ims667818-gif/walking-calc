# 내 걸음수 환산기

걸음수를 넣으면 치킨 몇 마리인지, 서울에서 부산까지 몇 번인지 알려주는 계산기.
설치도 로그인도 없이 링크만 열면 바로 씁니다.

**바로 쓰기** → https://ims667818-gif.github.io/walking-calc/

## 기능

- 기간: 1개월 / 6개월 / 1년 / 직접 입력
- 걸음수 또는 거리(km) — 둘 중 하나만 넣어도 자동 환산
- 몸무게(기본 55kg)로 칼로리 보정
- 결과: 총 걸음·거리·칼로리 → 치킨·엽떡·아메리카노·밥 / 서울↔부산 왕복·한라산 성판악·마라톤 풀코스 / 1년 체지방 환산 / "+2,000보" 시뮬레이션
- 결과 카드 이미지 저장 (HTML5 canvas, 1080×1350)

## 계산 기준

- 1걸음 = 0.65m
- 칼로리 = 걸음 × 0.0006 × 몸무게(kg) — 55kg이면 약 30걸음에 1kcal
- 체지방 1kg = 7,700kcal
- 치킨 2,000 / 엽떡 1,500 / 아메리카노 10 / 밥 300 kcal
- 서울→부산 400km(왕복 800km), 한라산 성판악 코스 왕복 19.2km, 마라톤 42.195km

재미로 보는 숫자입니다. 의학적 조언이 아닙니다.
